## The five `requested_only` steps

`motion:s1..s3` and `transition:s1->s2`, `transition:s2->s3` stay
`requested_only` on purpose. They record that a command was accepted.
The evidence that the effect reached the picture is in the separate
`verify:motion` and `verify:transitions` steps, which carry measurements.
Merging the two would hide exactly the distinction this repository exists
to preserve.
